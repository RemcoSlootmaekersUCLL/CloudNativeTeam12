# Cloud Native Engineering Team 12

## Front-End Development

To start running the project locally, run:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website

## Back-End Development

To start running the project locally, make sure you have [MongoDB](https://www.mongodb.com/products/tools/compass) installed.
Then run the back-end by executing `FitnessHealthTrackingApplication.java`.
