# Cloud Native Engineering Team 12

## Front-End Development

To start running the project locally, run:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website

## Back-End Development

You can run the back-end locally by running the file `FitnessHealthTrackingApplication.java`. The back-end will become available at [http://localhost:8080](http://localhost:8080)
